# ai-software-dev-template

Plantilla de entorno de ingeniería para desarrollar con Claude Code en la nube: proceso AI-native SDLC, skills de buenas prácticas, seguridad y control de tokens.

- Qué incluye y cómo aplicarlo: [docs/SETUP.md](docs/SETUP.md)
- Proceso de trabajo: [docs/SDLC.md](docs/SDLC.md)
- Investigación de respaldo: [docs/research/engineering-setup.md](docs/research/engineering-setup.md)

Aplicar a otro repo:

```bash
scripts/apply-template.sh /ruta/al/otro/repo
```

Los skills de terceros en `.claude/skills/` conservan su licencia original; ver `.claude/vendor/licenses/`.
